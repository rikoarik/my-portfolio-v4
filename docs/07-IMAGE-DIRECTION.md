# Image & Visual Direction

Dokumen ini khusus visual. Jangan campur dengan copy halaman.

## Overall Direction

Referensi rasa visual:
- editorial
- clean
- large whitespace
- typography-led
- project-first
- premium but restrained

Jangan membuat pixel-perfect clone dari portfolio referensi.

## Color

Primary:
- warm white / off-white
- near black
- neutral gray

Optional accent:
- satu subtle accent saja

Hindari:
- neon gradient
- glassmorphism berat
- warna terlalu banyak
- card dashboard style

## Image Style

Project image harus terasa seperti editorial product presentation.

Gunakan:
- clean device mockups
- cropped UI screens
- dashboard/browser frames
- close-up feature detail
- workflow diagram jika benar-benar membantu
- full-bleed product image

Jangan gunakan:
- stock photo programmer
- random laptop photo
- AI-generated fake dashboard
- floating tech logo
- fake metrics
- decorative code screenshots tanpa konteks

## Ratio

Recommended:
- Homepage project cover: 16:10 atau 4:3
- Case study hero: 16:9 atau 3:2
- Mobile feature shot: 4:5 atau portrait
- Technical diagram: wide 16:9

## Image Background

Gunakan background sederhana:
- off-white
- light gray
- charcoal
- muted neutral

Setiap project boleh punya satu tone berbeda, tapi jangan menjadi rainbow portfolio.

## Device Mockup

Gunakan device frame secukupnya.

PUAS / Member apps:
- phone mockup
- 2–3 screens maximum per composition

Web/backend project:
- browser/dashboard screenshot
- architecture/data-flow image bila relevan

## Alt Text

Setiap image wajib punya alt text deskriptif.

Contoh:
`PUAS Hub transaction history and digital product purchase screens`

Bukan:
`Project image 1`
