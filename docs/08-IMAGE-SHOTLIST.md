# Image Production Checklist

For each project prepare:
- 1 cover
- 3–5 detail images
- 1 optional technical diagram
- alt text
- caption
- source note: screenshot / diagram / mockup

Recommended source format:
- PNG for UI
- SVG for diagrams
- WebP/AVIF for production delivery
