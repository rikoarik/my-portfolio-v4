# ARK Portfolio — Documentation Index

Dokumentasi ini dipisah per concern agar konten, visual, project case study, dan implementasi tidak tercampur.

## Tujuan

Membangun portfolio baru untuk **Arik Riko Prasetya (Ark)** dengan positioning utama:

**Software Engineer**  
**Mobile · Backend · Full-stack**

Portfolio harus relevan untuk lowongan:
- Software Engineer
- Full-stack Developer
- Backend Developer
- Mobile Developer
- Android Developer
- Flutter Developer
- React Native Developer
- Frontend / Next.js Developer
- Junior Python Developer
- Junior Odoo Developer

Portfolio tidak boleh terlihat seperti "bisa semua tanpa fokus". Identitas utama tetap **Software Engineer**, sementara breadth dibuktikan melalui project.

## Prinsip Utama

1. Jangan jadikan homepage sebagai CV panjang.
2. Project adalah bukti utama kemampuan.
3. Detail teknis dipindahkan ke halaman case study.
4. Jangan mengarang metric, user count, revenue, atau impact.
5. Jangan menyebut Odoo sebagai pengalaman profesional; gunakan `Odoo (Basic)`.
6. Hanya PT Teknologi Kartu Indonesia yang memakai `Present`.
7. Tidak ada project yang memakai `Present`.
8. Design minimal, editorial, project-first, dan bukan developer-dashboard.
