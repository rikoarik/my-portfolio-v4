## OpenGraph

Required:
- title
- description
- canonical URL
- OG image
- type=website

## Project Metadata

Each project case study should have:
- unique title
- description
- canonical URL
- project image
- OpenGraph metadata

Example:

`PUAS Hub — PPOB & Digital Payment | Arik Riko Prasetya`

## Structured Data

Use Person schema with factual fields only:
- name
- url
- sameAs GitHub
- sameAs LinkedIn
- jobTitle: Software Engineer

Optional:
- knowsAbout

Do not create fake Organization relationships.

## Technical SEO

- sitemap.xml
- robots.txt
- canonical URLs
- proper heading hierarchy
- semantic HTML
- image alt text
- no duplicate metadata
